# Wall Sprint

## About the game
Wall Sprint is a vertigo-inducing parkour runner where you sprint, leap and
wall-run across rooftops suspended high above the city. Momentum is
everything: chain wall-jumps, slide under barriers and thread impossible
gaps while the buildings blur past. Every level is a hand-tuned sprint line,
and shaving a second off your best run is the whole addiction.

The magic is in the flow: the controls are simple but the level design keeps
finding new ways to test your rhythm, and a clean run feels like flying.

## Controls

### Smartphone & tablet
- **Tap the left side of the screen** — jump
- **Swipe up** — wall-run / climb
- On-screen hints guide you through the first rooftop.

### Desktop
- **Space / W / Up arrow / Left click** — jump
- **S / Down arrow** — slide
- **Move the mouse** — steer and wall-run
> Trackpad: single click = same as left-click.
